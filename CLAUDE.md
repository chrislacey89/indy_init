## Learning more about Effect

This repository uses the Effect Typescript library (v4) for the AI-path server code.

Before writing any Effect code, first read `node_modules/effect/AGENTS.md`. Effect v4 APIs differ from v3 (for example `Effect.catch`, not `catchAll`).
